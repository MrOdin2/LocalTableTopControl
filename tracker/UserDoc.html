Overview

The Initiative Tracker manages turn order and combat statistics for every player character and monster in an encounter. It keeps track of:

  • Initiative order (the sequence in which combatants act).
  • Hit Points (HP) — the combatant's current health.
  • Armour Class (AC) — the combatant's defence rating.
  • Round number — how many complete turns have passed.

Each combatant is shown as a card in the tracker. The currently active combatant's card is highlighted with the accent colour border.

The tracker also integrates with the Map plugin — adding a combatant can automatically place a token on the map. See Map Integration and Cross-Plugin Features for details.

Adding Combatants

Click the Add Combatant button (or the + icon) in the tracker toolbar. A new card appears at the bottom of the list with placeholder values.

Fill in the combatant's details directly on the card — all fields are editable in place (see Combatant Cards below).

Tip: Add all combatants before the encounter starts, then drag-and-drop the cards into initiative order (highest initiative at the top) before clicking Next Turn.

Editable Fields

FieldDescription
NameThe combatant's name. Click the name text to edit it.
HP (Hit Points)Current hit points. Click to edit. You can type a new value directly.
AC (Armour Class)Armour class. Click to edit.

All fields are edited in place — just click on the value and type. Press Enter or click elsewhere to confirm.

Colour Swatch

Each combatant is assigned a colour. The circular colour swatch on the card shows that colour. The same colour is used for the combatant's token on the map.

Click the swatch to open a colour picker and choose a different colour. The token on the map updates immediately.

Token Image

You can assign a custom image (portrait or token art) to each combatant. Click the Upload Image button on the card and select an image file from your computer.

The image appears on the combatant's token on the map. You can also adjust the image scale and offset within the token circle using the controls that appear after uploading.

To remove an image, upload a new one or use the remove button that appears when an image is set.

Managing Turns

Next Turn

Click the Next Turn button in the tracker toolbar to advance to the next combatant. The active card border moves to the next card in the list.

When the last combatant's turn ends, the tracker wraps back to the first combatant and increments the round counter.

Round Counter

The current round number is displayed in the tracker toolbar. It starts at 1 when the first Next Turn is pressed and increments automatically at the end of each complete round.

Reordering Combatants

Drag a combatant card to a new position in the list to change the turn order. This is useful when:

  • The players roll their initiative after the monsters have already been entered.
  • A combatant delays their action and needs to go later in the round.
  • You want to group similar enemies together visually.
Tip: During a drag, the card being dragged becomes semi-transparent and the target position is highlighted in a different colour so you can see exactly where the card will land.

Map Integration

The Initiative Tracker and Map plugin work together — combatants in the tracker can have corresponding tokens on the map. See the dedicated Cross-Plugin Features page for a full explanation of how tokens are created, moved, and updated.

In brief:

  • Adding a combatant can create a token on the map at a default position.
  • The token colour matches the combatant's colour swatch.
  • Uploading a token image in the tracker updates the token image on the map.
  • Removing a combatant removes its token from the map.

Clearing the Tracker

Click the Clear All button to remove all combatants from the tracker. A confirmation dialog appears before the action is taken.

Note: Clearing the tracker also removes all associated tokens from the map. This action cannot be undone.

Adaptive Layout

The tracker automatically adapts to the available panel size:

  • Wide panel — combatant cards are arranged horizontally, scrolling left and right only when the panel is more than twice as wide as it is tall. This is ideal when the tracker occupies a full-width panel at the bottom of the DM screen.
  • All other panel shapes — combatant cards stack vertically, scrolling up and down. This is better when the tracker is displayed in a side column or only slightly wider than tall.

The layout switches automatically as you resize the DM panel using the split-pane dividers.
