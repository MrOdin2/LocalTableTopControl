New Tracker

TabletopControl User Documentation

Overview

New Tracker lets you keep a simple combat list with editable actor names, hit points, armour class, initiative, PC/NPC type, and token pictures.

The active actor is highlighted, and the tracker updates the linked map token details automatically as you edit each card.

Adding And Editing Actors

Use + to add a new actor. Each actor card lets you:

  • Edit the actor name directly in the card.
  • Change HP, AC, and initiative values.
  • See whether the actor is marked as a PC or NPC.
  • See any configured darkvision, light source, or movement range at a glance.
  • Duplicate or delete the actor.
  • Assign a token picture and adjust its scale or offset.

Right-click an actor card to mark that actor as a PC or NPC, open Features..., or change the token size used on the map.

In DynamicMap, actors marked as PC also act as sightline sources. Moving a PC token updates what the players can see through the dynamic map's exported walls.

The Features dialog lets you turn darkvision on or off, set its range, add a carried light source with bright and dim ranges plus a tint colour, and record the actor's movement range in feet or meters. When the actor is marked as a PC, DynamicMap uses that darkvision range to reveal nearby terrain in black and white, and uses the light source as a moving point light attached to the PC token. DynamicMap also keeps remembered terrain grayscale after the PC moves away.

DynamicMap uses the movement range for turn reachability highlights. PCs can use their web controls to spend movement and Dash. NPC movement highlights are DM-only on the DynamicMap minimap; press Shift once while that minimap has focus to add an NPC Dash. If Shift is pressed during a token drag, the Dash is applied when the token is dropped.

Use NEXT to advance to the next actor with an initiative value.

If multiple actors share the same initiative, New Tracker opens a drag-and-drop list so you can arrange that tied group in the exact order you want.

Initiative changes are applied when you press Enter in the initiative field or when you click away from that field.

Preset Library

Use SAVE on any actor card to store that actor as a reusable preset. The preset keeps the actor's name, HP, AC, PC/NPC type, darkvision, light source, and movement settings, token size, and token picture settings.

If you save using a name that already exists in the preset folder, New Tracker asks whether you want to overwrite that preset before anything is replaced.

Use Presets... in the toolbar to open the preset library. From there you can:

  • Load a preset to create a new actor card.
  • Delete saved presets you no longer need.
  • Open the preset folder in your system file manager.

Presets are stored as .preset files in ~/.tabletopcontrol/presets/. This library is compatible with the existing Initiative Tracker preset files, so both trackers can use the same saved presets.

Initiative is not restored from presets in New Tracker. After loading a preset, roll initiative as usual and enter the result for the current encounter.

Token Pictures

When a preset contains a token picture, New Tracker restores that picture automatically after loading. This helps shared presets keep their visual identity across sessions and across different machines.

When you click the picture chooser again, it reopens in the last folder you used for token art, which makes assigning several portraits or tokens much quicker.

Scenes

Use Scenes... from the main toolbar to save the current encounter as a reusable scene. The tracker portion keeps the live actor list, including current HP, AC, initiative, PC/NPC type, darkvision, light source, and movement settings, token size, token picture settings, and the active round.

Loading a scene replaces the current tracker setup after a confirmation dialog, which makes it practical to prepare encounters in advance and restore them later.

Scenes are broader than presets: a preset stores one reusable actor template, while a scene stores the tracker together with the linked map, audio, soundboard, and lighting setup.

Player Web Companion

The Player Web Companion is a small built-in web server that lets players control their own map token from any phone or tablet on the same network — no app installation needed.

Setting up

  1. Give each player character a unique actor name and mark that tracker actor as a PC (right-click the card → Actor Type → PC).
  2. Click Web: OFF in the tracker toolbar to start the server. The button changes to Web: ON and the URL is shown next to it (for example http://192.168.1.5:8765).
  3. Players open that URL on their device, select their character name from the drop-down, and tap Connect.

Player controls

After connecting, the player sees their character's current HP and AC, plus a directional pad with four buttons:

Players can update their own HP and AC from the web page. The tracker remains the source of truth, so the page also refreshes when the DM changes those values in the main application.

The page also shows the character's movement for the current round. Players can edit their normal movement, tap Dash to add that normal movement to the remaining amount, and tap Dash more than once if the round gives them more than one dash-like boost. Web moves spend one grid cell from the remaining movement after the live map accepts the move.

  • ↑ (North) — move the token one cell up on the grid.
  • ↓ (South) — move the token one cell down.
  • ← (West) — move the token one cell to the left.
  • → (East) — move the token one cell to the right.

Each tap sends a movement request to the DM machine, which moves the token on the live map immediately.

When the connected character is the current initiative actor, the web card is outlined in that actor's token colour. Their round movement resets to the normal movement value when their turn comes up again.

If the DM presses NEXT while any PC actor has no initiative value, connected player screens show a required initiative prompt. The player must submit their initiative before using the web controls again, and the value is written back to the tracker. If that initiative ties with another actor, the DM gets the same tie-order dialog as when editing initiative in the tracker. If more players submit the same initiative while that dialog is open, they are added to the existing list. NPC actors can be left without initiative.

HTTP API

The server also exposes a simple REST API for custom integrations (default port 8765):

Method & Path Description
GET / The mobile-optimised player web app.
GET /api/players JSON array of PC actor names.
GET /api/state?player=<name> JSON object with fields name, hp, ac, initiative, inInitiative, tokenX, tokenY, activeTurnColor, movementAmount, movementUnit, remainingMovement, and usedMovement.
PUT /api/stats?player=<name>&hp=<hp>&ac=<ac> Update the PC actor's HP and AC; returns updated state JSON.
PUT /api/initiative?player=<name>&initiative=<initiative> Update the PC actor's initiative; returns updated state JSON.
PUT /api/movement?player=<name>&amount=<amount>&unit=<FEET|METERS> Update the PC actor's normal movement; returns updated state JSON.
PUT /api/dash?player=<name> Add the actor's normal movement to the current round's remaining movement; returns updated state JSON.
PUT /api/move?player=<name>&dir=<n|s|e|w> Move token one cell; returns updated state JSON.
GET /api/events Server-sent applicationUpdate and initiativeRequired events used by the web page to refresh from the tracker.

Notes

  • The server runs on port 8765 by default.
  • The server only runs while Web: ON is active — it is off by default.
  • Connected pages listen for live application updates and re-read their selected actor from the tracker.
  • Token positions are tracked in memory; they reset when the server is restarted.
  • Only actors marked as PC are visible in the player list.
  • Token movement via the web companion is subject to the same grid-cell boundaries as DM movement.
