Overview

TabletopControl provides two separate audio plugins that can be displayed side-by-side in the DM panel:

  • Music Player — three independent audio tracks for layered ambient soundscapes (e.g. background music, atmospheric sounds, and environmental loops all playing at once).
  • Soundboard — customizable quick-fire buttons (up to 32) for instant sound effects (combat hits, door creaks, tavern noise, etc.).

All audio is loaded from files on your computer. No internet connection is required for playback.

Music Player

The Music Player provides three independent tracks that play simultaneously, each with its own file, playback controls, and volume slider. Use them to layer a background music track, a wind or rain loop, and a subtle tavern ambience all at once.

Loading Tracks

Each of the three track rows has a Browse (or file picker) button. Click it and select an audio file from your computer. Supported formats include MP3 and other formats supported by your Java runtime.

The file name is shown next to the button once a track is loaded. You can change the file at any time — even while the other tracks are playing.

Playback Controls

ControlDescription
▶ Play / ⏸ PauseStart or pause playback of this track. The button toggles between the two states.
⏹ StopStop playback and reset the position to the beginning.
Progress barShows how far through the track you are. The elapsed and total time are displayed alongside it.

Volume & Loop

ControlDescription
Volume sliderSets the volume for this individual track (0–100%). Independent of the other tracks and the master volume.
Loop checkboxWhen ticked, the track restarts automatically when it reaches the end. Ideal for ambient loops.
Tip: Enable looping on all three tracks and set them to different lengths so they fall in and out of sync, creating a naturally evolving soundscape.

Master Controls

At the bottom (or top) of the Music Player panel you will find master controls that affect all three tracks together:

ControlDescription
Master VolumeA global volume multiplier applied on top of each track's individual volume.
Stop AllImmediately stops all three tracks and resets their positions to the beginning.

Soundboard

The Soundboard gives you a customizable set of instant-play buttons arranged in a grid (default: 16, maximum: 32). Each button can be loaded with a sound effect that plays immediately when clicked — perfect for combat sounds, door slams, thunder claps, and anything else that needs to happen right now.

Loading Sounds

Right-click any button to open a file chooser and load a sound file onto that button. The button label updates to show the file name (or a shortened version of it).

You can right-click a button that already has a sound to replace it with a different file.

Customizing Buttons

ActionDescription
+ Add ButtonAdds a new empty soundboard button until the maximum (32) is reached.
Inline + TileWhen the current buttons do not fill a complete grid rectangle, a + tile appears in-grid as the next slot position. When the grid is a perfect rectangle, this inline tile is hidden to preserve the rectangular shape.
Remove ButtonRight-click a button and choose Remove Button to delete that slot.
Drag & DropClick and drag a button to a new position to reorder slots with immediate visual feedback.
Set ColorRight-click a button and choose Set Color to open an in-dialog color wheel (with brightness slider) and apply a custom button color.

Soundboard layout and button settings (loaded sound, order, and color) are persisted between sessions.

Playing Sounds

Left-click a loaded button to play the sound immediately. The button indicates whether a sound is currently playing. When the sound finishes, the button resets automatically — ready for the next click.

Clicking the same button again while a sound is still playing restarts it from the beginning.

Tip: Assign your most-used effects to the first row of buttons so they are always visible, even when the soundboard panel is narrow.

Responsive Layout

The soundboard adapts to the available panel width:

  • Wide panel — 8 buttons per row (2 rows of 8).
  • Narrow panel — 2 buttons per column (8 rows of 2).

The layout switches automatically as you resize the DM panel. All configured buttons remain accessible regardless of the panel size.
