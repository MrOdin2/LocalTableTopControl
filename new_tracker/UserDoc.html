New Tracker

TabletopControl User Documentation

Overview

New Tracker lets you keep a simple combat list with editable actor names, hit points, armour class, initiative, and token pictures.

The active actor is highlighted, and the tracker updates the linked map token details automatically as you edit each card.

Adding And Editing Actors

Use + to add a new actor. Each actor card lets you:

  • Edit the actor name directly in the card.
  • Change HP, AC, and initiative values.
  • Duplicate or delete the actor.
  • Assign a token picture and adjust its scale or offset.

Use NEXT to advance to the next actor with an initiative value.

Preset Library

Use SAVE on any actor card to store that actor as a reusable preset. The preset keeps the actor's name, HP, AC, and token picture settings.

Use Presets... in the toolbar to open the preset library. From there you can:

  • Load a preset to create a new actor card.
  • Delete saved presets you no longer need.
  • Open the preset folder in your system file manager.

Presets are stored as .preset files in ~/.tabletopcontrol/presets/. This library is compatible with the existing Initiative Tracker preset files, so both trackers can use the same saved presets.

Initiative is not restored from presets in New Tracker. After loading a preset, roll initiative as usual and enter the result for the current encounter.

Token Pictures

When a preset contains a token picture, New Tracker restores that picture automatically after loading. This helps shared presets keep their visual identity across sessions and across different machines.
