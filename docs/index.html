What is TabletopControl?

TabletopControl is a lightweight companion application for tabletop RPG sessions (D&D, Pathfinder, and similar games). It drives two screens simultaneously: one facing the players (showing the map at physical scale) and one for the Dungeon Master (a full control panel).

No internet connection is needed. No subscription. Just a desktop application that runs even on modest hardware such as a Raspberry Pi.

Two-Screen Setup

Table Screen (Player View)

The table screen is designed to be placed flat on the table, or projected onto a surface, so that physical miniatures can be placed on top of it. It shows:

  • The full map image, scaled to match real-world miniature sizes.
  • An optional grid overlay aligned to the map's coordinate system.
  • Fog of war — unexplored areas are hidden until the DM reveals them.
  • Tokens representing combatants, placed on the correct grid cells.

The table screen updates automatically whenever the DM makes changes on the DM screen. Players always see the current state without any extra interaction.

Tip: If you have multiple monitors, you can move the table screen to any connected display from the DM screen's application menu.

DM Screen (Control Panel)

The DM screen is the main control interface. It hosts all loaded plugins in a split-pane layout. From here the DM can:

  • Load and control the map.
  • Paint or erase fog of war.
  • Manage the initiative order and combatant HP/AC.
  • Control background music and sound effects.
  • Control ambient lighting via WLED devices.

DM Panel Layout System

The DM panel uses a recursive split-pane layout — similar to the panel system in IDEs such as VS Code or IntelliJ — so you can arrange any combination of plugins side-by-side. No tab-switching required.

On first launch, a single plugin pane fills the DM window. You can split it into as many panels as you like and arrange them however suits your workflow.

Context Menu

Right-click anywhere on a pane to open the layout context menu:

ActionWhat it does
Add Panel to LeftSplits the current pane left–right and inserts a new plugin pane on the left.
Add Panel to RightSplits the current pane left–right and inserts a new plugin pane on the right.
Add Panel AboveSplits the current pane top–bottom and inserts a new plugin pane above.
Add Panel BelowSplits the current pane top–bottom and inserts a new plugin pane below.
Change Plugin…Opens a dialog to swap the plugin shown in this pane for a different one.
Close PaneRemoves this pane. Disabled when it is the only pane remaining.
Extend Left / Right / Above / BelowExpands this pane into exactly one neighbouring pane's space (see below).

Extending Panes

The Extend options let you grow a pane without rearranging the rest of the layout manually. Only directions that have a compatible single neighbouring pane are shown — so the menu only ever offers valid moves. The neighbouring pane's content is consumed and the layout restructured accordingly.

Example: You have the Map pane on the left and two stacked panes (Tracker on top, Music on bottom) on the right. Right-clicking Map and choosing Extend Right will remove the Tracker pane and expand the Map to fill the freed space, while Music remains in place.

Saving Your Layout

Your layout — including which plugins are in which panes and how the dividers are positioned — is saved automatically when you close the application. The next time you launch TabletopControl, the exact same arrangement is restored.

The layout is stored in ~/.tabletopcontrol/dm-layout.conf. You can delete this file to reset the layout to its default (single-pane) state.

Theme & Appearance

TabletopControl supports light and dark modes, plus user-selectable colours for the four key UI roles: accent, background, surface panels, and borders.

Open the theme settings from the application menu. Changes apply immediately across all open panes. Your theme preferences are saved to ~/.tabletopcontrol/theme.conf and restored on the next launch.

SettingWhat it affects
Mode (Light / Dark)Overall colour scheme — light background or dark background.
Accent colourButtons, links, active highlights, and the current-turn border in the tracker.
Background colourThe main window / scene background.
Surface colourPanel and card surfaces (e.g. combatant cards in the tracker).
Border colourPanel edges and control borders.
Tip: If you reset the theme to defaults, all four colour settings return to the built-in values for the selected mode.
