Overview

While each plugin works independently, the Initiative Tracker and Map plugins share information automatically so you don't have to manage tokens on the map separately from the combat tracker.

The link between them is one-way: the Tracker publishes information (combatant added, moved, image changed, removed) and the Map listens and updates the table screen accordingly. You control everything from the Tracker side.

Tracker ↔ Map Integration

Token Creation

When you add a combatant to the Initiative Tracker, a corresponding token is automatically created on the map. The token appears at a default position and can be moved to the correct location on the grid (see Positioning Tokens below).

Each token is uniquely tied to one combatant. If you add ten goblins, ten separate tokens appear — one per combatant card.

Colour Sync

The token's colour circle on the map always matches the combatant's colour swatch in the tracker. Changing the swatch colour in the tracker immediately updates the token colour on the map.

This lets you quickly distinguish between combatants at a glance — especially useful when there are several tokens of the same type on the map (e.g. multiple goblins). Assign each a distinct colour.

Size Sync

Token size is also shared between the tracker and the map. Right-click a combatant card in the tracker to choose Tiny (1/8 tile), Small (1/4 tile), Medium (1 tile), Large (2x2 tiles), Huge (3x3 tiles), or Gargantuan (4x4 tiles).

The map redraws the token immediately at the matching footprint, and older presets or saved data that do not include a size continue to use Medium.

If footprints overlap, smaller tokens are rendered above larger ones so tiny and small creatures stay readable on the table screen.

Token Images

When you upload a token image on a combatant's card in the tracker, that image is sent to the map and shown inside the token circle on the table screen.

You can also adjust the image scale and offset within the token circle from the tracker card. These adjustments are reflected on the map in real time.

Tip: Use circular portrait art (tokens) for the best appearance. Square or rectangular images work too — the circular clip just crops the edges.

Positioning Tokens on the Map

Token positions are managed through the minimap on the DM panel of the Map plugin. You can drag tokens on the minimap to move them to the correct grid cells. The table screen updates instantly.

Tokens snap to the map grid when a grid is enabled, so they stay aligned to grid squares automatically.

Multi-cell tokens can be grabbed from any covered cell on the minimap, and fog of war checks the whole footprint instead of only the token's top-left corner.

Tip: Use the Map plugin's minimap to move tokens during combat. The players see the updated position on the table screen as soon as you drop the token.

Removing Tokens

When you remove a combatant from the tracker (using the remove button on the combatant card, or via Clear All), the corresponding token is automatically removed from the map as well. No manual cleanup is needed.

Note: Using Clear All in the tracker removes every combatant and every token at once. A confirmation dialog is shown before this action proceeds.

Showing Token Names

The Map plugin has a Show Token Names toggle. When enabled, each token on the table screen displays a text label with the combatant's name drawn beneath the token circle. When disabled, tokens are shown as circles (or portrait images) only.

The name shown on the token always matches the name on the combatant's card in the tracker. Editing the name in the tracker updates the map label automatically.

Recommended Workflow for a Session

  1. Before the session: Load your map in the Map plugin and calibrate it. Set up fog of war — Hide All to cover the entire map.
  2. When an encounter begins: Add all combatants to the Initiative Tracker. Assign each a distinct colour and, optionally, a token image.
  3. Position tokens: Drag each token to its starting position on the minimap. Reveal the relevant fog of war area so the players can see the encounter space.
  4. During combat: Click Next Turn in the tracker to advance turns. Move tokens on the minimap as combatants move. Update HP and AC on the tracker cards as damage is dealt.
  5. After the encounter: Click Clear All in the tracker to remove all combatants and their tokens. Re-hide revealed fog of war if needed before the players explore further.
