Overview

The Map plugin is the heart of TabletopControl. It renders a high-resolution map image on the table screen at physical scale so that miniatures can be placed directly on the surface. On the DM screen it shows a minimap preview and all controls.

Key capabilities:

  • Load any image file as a map (JPEG, PNG, BMP, and other common formats).
  • Remove the current map image and fall back to a plain background colour.
  • Calibrate scale so the rendered map matches real-world miniature scale (typically 1 inch per grid square).
  • Overlay a customisable grid aligned to the map's coordinate system.
  • Paint fog of war to hide unexplored areas from the players.
  • Place and move tokens representing combatants on the map.
  • Create measurement overlays (Line, Cone, Rectangle, Circle) with optional table mirroring.
  • Rotate the map in 90° increments.

Loading a Map

Click the Load Map button on the DM panel. A file chooser opens — navigate to your map image and select it. The map appears immediately on the table screen.

The chooser remembers the last map folder you used, so reopening Load Map starts from that location instead of sending you back to a default folder.

If you want to stop using an image and return to a simple coloured table, click Remove Map. The image is cleared immediately and the table shows only the current background colour and any active overlays such as grid, fog, tokens, or measurements.

The minimap preview in the DM panel shows a scaled-down copy of the map with the fog of war overlay and token positions. Use the minimap to get an overview at a glance and to paint fog of war (see Fog of War).

Tip: High-resolution maps (2000 × 2000 px and above) give the sharpest results when scaled to fit the physical table.

Map Calibration

Calibration sets the scale and position of the map on the table screen so miniatures are correctly sized and aligned with grid squares.

TabletopControl offers a Guided Calibration workflow:

  1. Click Guided Calibration to open the guided calibration dialog.
  2. Step 1 — Centre Point: Drag the map with the mouse for coarse positioning, then use the on-screen arrows or the keyboard arrow keys to move the blue cursor by exactly one calibration-screen pixel at a time until it sits on the centre reference.
  3. Step 2 — Next Tile Boundary: The centre point from Step 1 stays marked. Choose whether the second point should be horizontal or vertical, then place the blue cursor on the start of the next tile on that axis. Diagonal points are not used.
  4. Wide Mode: If you want extra precision, enable Wide mode and enter how many tiles away the Step 2 point should be. Instead of using the very next tile boundary, you can measure to the nth boundary on the same axis, which makes tiny placement errors matter less.
  5. Confirm. The scale and offset are applied immediately to the table screen.
Tip: The mouse is always available for coarse panning, while both the on-screen arrows and the keyboard arrows move the active point by exactly one calibration-screen pixel. The deeper you zoom in, the finer those nudges become on the map itself.

Grid Overlay

Enabling the Grid

Toggle the grid on or off with the Show Grid checkbox or button on the DM panel. When enabled, a grid is drawn on top of the map image on the table screen.

Grid appearance settings:

SettingDescription
Cell sizeThe size of one grid square in screen units. Adjust to match your map's grid.
Line colourColour of the grid lines. The plugin can also pick an automatic contrasting colour based on the map image.
Line widthThickness of the grid lines in pixels.

Grid Calibration

Use Calibrate Grid to align the grid precisely to the map image. This is a separate step from map calibration and only affects the grid offset and scale, not the map image itself.

After calibration, the grid lines should line up with the printed grid (or intended grid squares) of the map image.

Calibration, grid colour, background colour, and map rotation are saved between sessions in ~/.tabletopcontrol/map-settings.conf.

Fog of War

Fog of war hides portions of the map from the players. Cells are either hidden (opaque overlay on the table screen) or revealed (fully visible). The DM controls which cells are revealed.

Painting & Erasing

Use the minimap on the DM panel to paint or erase fog of war:

  • Left-click and drag on the minimap — reveals cells (removes fog).
  • Right-click and drag on the minimap — hides cells (adds fog back).

The brush size corresponds to the grid cell size. Each cell you paint over changes state. Changes appear on the table screen in real time.

Bulk Controls

ButtonEffect
Reveal AllRemoves all fog — the entire map becomes visible to players.
Hide AllCovers the entire map with fog — nothing is visible to players.
Tip: Start each session with Hide All, then gradually reveal areas as the players explore. This keeps the mystery intact even if the map is already loaded.

Tokens

Tokens are visual markers placed on the map that represent combatants. They are managed through the Initiative Tracker plugin — when you add a combatant in the tracker, a corresponding token can appear on the map.

Each token can display:

  • A colour circle matching the combatant's assigned colour.
  • A footprint size from Tiny (1/8 tile) up to Gargantuan (4x4 tiles).
  • A custom image (portrait or token art) uploaded in the tracker.
  • The combatant's name label (toggle with the Show Token Names option).

Token positions are set via the tracker's drag-and-drop placement, or by dragging the token directly on the minimap. See Cross-Plugin Features for the full details of how the tracker and map work together.

Large footprints stay aligned to the grid automatically. A Large token covers 2x2 cells, a Huge token covers 3x3 cells, and a Gargantuan token covers 4x4 cells. Tiny and Small tokens render inside a single anchor cell at one-eighth and one-quarter tile size.

On the DM minimap you can grab a multi-cell token from any covered cell and drag it without losing its footprint alignment. On the table screen, fog of war respects the full token footprint so oversized creatures only appear where their occupied cells are visible.

When tokens overlap, smaller footprints are drawn on top of larger ones so tiny and small creatures remain visible instead of disappearing underneath large bases.

Tip: Change token size from the linked tracker card by right-clicking the combatant and opening the Token Size menu.

Measurement Tools

Use the minimap Measure tool buttons to place tactical overlays that snap to grid cells. Supported shapes are Line, Cone, Rect, and Circle.

  • Select a shape button, then left-click and drag on the minimap.
  • Measurements are labeled automatically with size in the selected Units (ft or m).
  • Use the Cone angle selector for cone templates (15° to 120°).
  • Enable Mirror to show new measurements on the table screen; leave off for DM-only overlays.

Right-click actions (DM minimap)

ActionEffect
Units: feet / metersChanges units used by future measurement labels.
Mirror to Table / Hide from TableToggles visibility on the player table for the selected measurement.
Set Label…Adds or edits a custom label prefix for the selected measurement.
Remove MeasurementDeletes the selected measurement.
Clear All MeasurementsRemoves all active measurements.
Tip: Keep Mirror off for private planning, then toggle individual templates to mirrored when you want players to see intent/area.

Map Rotation

Use the Rotate button on the DM panel to rotate the map in 90° increments. This is useful when a map image is saved in landscape orientation but needs to be displayed in portrait orientation on the table screen, or vice versa.

Rotation affects the table screen display only — the original image file is not modified. The grid and fog of war rotate with the map.

Background Colour

The area around the map image (visible when the map does not fill the entire screen) can be set to a custom background colour. Click BG Color on the DM panel and pick a colour from the colour picker.

When no map image is loaded, this background colour becomes the entire player-facing map. This is useful for theatre-of-the-mind scenes, quick sketches, or breaks between maps without loading a new image.

Setting a dark background (such as black) works well for dungeon maps where the edges should appear as darkness; a blue background can simulate ocean or sky.

Scenes

Use Scenes... in the main toolbar to capture the current map setup as part of a reusable scene. The map portion of a scene includes the loaded image, calibration, rotation, background, grid visibility, token positions, and fog of war state.

Loading a scene asks for confirmation before it replaces the current encounter setup. After you confirm, the table screen updates to the saved map state and the DM controls reopen in that same state.

Tip: Scenes are ideal for prepared encounters. Set up the map, fog, token starting positions, and supporting plugins ahead of time, then load the whole encounter in one step when you need it.
