Overview

The Map plugin is the heart of TabletopControl. It renders a high-resolution map image on the table screen at physical scale so that miniatures can be placed directly on the surface. On the DM screen it shows a minimap preview and all controls.

Key capabilities:

  • Load any image file as a map (JPEG, PNG, BMP, and other common formats).
  • Calibrate scale so the rendered map matches real-world miniature scale (typically 1 inch per grid square).
  • Overlay a customisable grid aligned to the map's coordinate system.
  • Paint fog of war to hide unexplored areas from the players.
  • Place and move tokens representing combatants on the map.
  • Rotate the map in 90° increments.

Loading a Map

Click the Load Map button on the DM panel. A file chooser opens — navigate to your map image and select it. The map appears immediately on the table screen.

The minimap preview in the DM panel shows a scaled-down copy of the map with the fog of war overlay and token positions. Use the minimap to get an overview at a glance and to paint fog of war (see Fog of War).

Tip: High-resolution maps (2000 × 2000 px and above) give the sharpest results when scaled to fit the physical table. Maps downloaded from sites like Dungeon Alchemist or Inkarnate work well.

Map Calibration

Calibration sets the scale and position of the map on the table screen so miniatures are correctly sized and aligned with grid squares.

TabletopControl offers a Guided Calibration workflow:

  1. Click Calibrate Map to open the calibration dialog.
  2. Step 1 — Grid Centre: Click the centre of any grid intersection on the map image in the dialog.
  3. Step 2 — Grid Corner: Click an adjacent grid corner (one cell away in any direction) to define the cell size.
  4. Confirm. The scale and offset are applied immediately to the table screen.
Tip: If the calibration looks slightly off, open the calibration dialog again and fine-tune by clicking a clearer intersection. The two-click process is designed to be fast and repeatable.

Grid Overlay

Enabling the Grid

Toggle the grid on or off with the Show Grid checkbox or button on the DM panel. When enabled, a grid is drawn on top of the map image on the table screen.

Grid appearance settings:

SettingDescription
Cell sizeThe size of one grid square in screen units. Adjust to match your map's grid.
Line colourColour of the grid lines. The plugin can also pick an automatic contrasting colour based on the map image.
Line widthThickness of the grid lines in pixels.

Grid Calibration

Use Calibrate Grid to align the grid precisely to the map image. This is a separate step from map calibration and only affects the grid offset and scale, not the map image itself.

After calibration, the grid lines should line up with the printed grid (or intended grid squares) of the map image.

Fog of War

Fog of war hides portions of the map from the players. Cells are either hidden (opaque overlay on the table screen) or revealed (fully visible). The DM controls which cells are revealed.

Painting & Erasing

Use the minimap on the DM panel to paint or erase fog of war:

  • Left-click and drag on the minimap — reveals cells (removes fog).
  • Right-click and drag on the minimap — hides cells (adds fog back).

The brush size corresponds to the grid cell size. Each cell you paint over changes state. Changes appear on the table screen in real time.

Bulk Controls

ButtonEffect
Reveal AllRemoves all fog — the entire map becomes visible to players.
Hide AllCovers the entire map with fog — nothing is visible to players.
Tip: Start each session with Hide All, then gradually reveal areas as the players explore. This keeps the mystery intact even if the map is already loaded.

Tokens

Tokens are visual markers placed on the map that represent combatants. They are managed through the Initiative Tracker plugin — when you add a combatant in the tracker, a corresponding token can appear on the map.

Each token can display:

  • A colour circle matching the combatant's assigned colour.
  • A custom image (portrait or token art) uploaded in the tracker.
  • The combatant's name label (toggle with the Show Token Names option).

Token positions are set via the tracker's drag-and-drop placement, or by dragging the token directly on the minimap. See Cross-Plugin Features for the full details of how the tracker and map work together.

Map Rotation

Use the Rotate button on the DM panel to rotate the map in 90° increments. This is useful when a map image is saved in landscape orientation but needs to be displayed in portrait orientation on the table screen, or vice versa.

Rotation affects the table screen display only — the original image file is not modified. The grid and fog of war rotate with the map.

Background Colour

The area around the map image (visible when the map does not fill the entire screen) can be set to a custom background colour. Click Set Background on the DM panel and pick a colour from the colour picker.

Setting a dark background (such as black) works well for dungeon maps where the edges should appear as darkness; a blue background can simulate ocean or sky.
