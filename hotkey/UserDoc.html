Overview

The Hotkeys plugin gives you a matrix of named cue buttons. Clicking a button and pressing its assigned shortcut run exactly the same actions. This is useful for ambience changes, dramatic effects, combat starts, and other cues that would otherwise need several panels and clicks.

The first launch creates twelve buttons assigned to F1 through F12. They have no actions until you configure them.

Button Matrix

Use Columns to choose a matrix width from 2 to 8 columns. + Add Hotkey adds another button; up to 64 buttons can be kept in the matrix.

Each button shows its optional icon, name, and assigned shortcut. A user-selected button colour is automatically given readable contrasting text.

Configure a Hotkey

  1. Right-click a hotkey button and choose Configure....
  2. Enter a name and, optionally, a short icon or emoji and button colour.
  3. Choose F1–F12 directly, leave the shortcut unassigned, or choose Custom shortcut and capture a key combination.
  4. Add, edit, remove, and reorder actions. Each hotkey supports up to 16 actions, including waits.
  5. Choose OK to save the changes.

Custom shortcuts support bare function keys through F24. Other keys must include Ctrl, Alt, or Meta so normal typing is not captured accidentally. A shortcut cannot be assigned to two hotkeys.

Tip: Right-click also offers Clear Actions and Remove Hotkey.

Available Actions

ActionWhat you can configure
Control Light / SegmentChoose the global light, all advanced-light segments, or specific segment numbers. Change any combination of power, colour, effect, brightness, effect speed, and effect intensity.
Play Sound FileChoose an audio file and playback volume. Hotkeys load and play this file themselves, so no Soundboard pane or configured Soundboard button is required.
Control Music TrackStart a chosen track, switch to it after stopping other music, stop one chosen track, or stop all music.
Trigger Another HotkeyRun another configured hotkey as part of the cue.
WaitPause this sequence for up to ten minutes before continuing with the next step.

Steps and Waits

Actions are read from top to bottom. Consecutive non-wait actions form one step and are started together. A Wait ends that step; when the delay finishes, all following actions up to the next wait form the next step.

For example: add “global light on”, then Wait 0.2 seconds, then “global light off” and “play thunder”. The final light and sound actions start together after the delay.

You may trigger another hotkey, but circular chains are stopped automatically. If A triggers B and B tries to trigger A again, the repeated trigger is ignored instead of looping.

Triggering Hotkeys

Left-click a matrix button or press its assigned shortcut while the DM window is active. Shortcuts keep working when another plugin pane is visible and do not require the Hotkeys pane to be open.

Holding a key does not repeatedly start the cue; release it before triggering that shortcut again.

Saving

Hotkey names, appearance, shortcuts, actions, order, and matrix columns are saved automatically in ~/.tabletopcontrol/hotkeys.conf.

Hotkeys also participate in TabletopControl scenes. Saving a scene captures the current Hotkey setup, and loading it replaces the matrix with the scene's saved setup.
