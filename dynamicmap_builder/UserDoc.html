Overview

The Dynamic Map Builder is a dedicated workspace for constructing the new Dynamic Map format. It runs alongside the existing Map plugin instead of replacing it.

This first version focuses on the map-building basics: grid-sized map bounds, a background texture, paintable soft, hard, door, and feature wall geometry, static point lights with reusable presets, and sunlight/outside areas drawn as polygons.

Builder Workspace

Use the Workspace selector in the DM toolbar and choose Dynamic Map Builder. That opens a separate pane layout just for builder tools.

The builder layout is saved independently from your regular session layout, so you can keep a focused editing setup without disturbing the main DM workspace.

While the Dynamic Map Builder workspace is active, the top DM toolbar also shows the construction-site selector, save controls, and gameplay export button. These controls disappear again when you switch back to the regular Session workspace.

WorkspaceSaved layout file
Session~/.tabletopcontrol/dm-layout.conf
Dynamic Map Builder~/.tabletopcontrol/dynamic-map-builder-layout.conf

Editing Tools

The main Dynamic Map Builder pane shows the whole map draft on a fitted grid. It now focuses on document-wide controls such as map size, layer visibility, background texture loading, and calibration.

Main builder controlWhat it does
Load / Clear TextureLoad a background texture or remove it from the current draft.
Calibrate Texture...Open numeric texture calibration with live preview.
Guided Calibration...Open the two-step guided texture calibration flow.
Map sizeChange the logical map width and height in grid cells.
Layer togglesTemporarily show or hide the background, walls, lights and sunlight areas, or grid.

Turn Snap 0.25 on to align new content to quarter-cell increments. This keeps the draft grid-friendly while still allowing more detail than full-cell snapping. The same snap setting is also used when moving selected walls or lights.

The main builder pane is intentionally lean. Use the builder toolbar for construction-site loading and saving, and supporting builder panes such as Wall Tools, Light Browser, and Outline Browser for editing workflows.

The layer toggles let you temporarily hide the background texture, walls, lights and sunlight areas, or grid while editing. Hiding a layer does not delete it.

Right-click near a wall, light, or sunlight area to remove that specific element. Right-click empty builder space to open the normal pane layout menu, so you can still split panes or switch to the Light Browser while staying in the builder workspace.

With no placement tool active, drag a selected wall, light, or sunlight area directly on the builder canvas to move it. If several outline items are selected, dragging any selected item moves the whole selection together. Drag empty canvas space to pan the workspace as before.

Arrow keys also nudge the selected items when the main builder pane has focus: plain arrows move by a quarter tile, Shift plus arrows move by one tile, and Ctrl plus arrows make a fine screen-pixel adjustment.

Press Escape in the builder pane to leave the current placement mode.

Zoom & Pan

The builder canvas supports view-only zoom and pan so you can inspect details without changing the map grid or any placed content.

ActionWhat it does
Mouse wheelZooms the builder workspace in or out.
Drag empty space with no active toolPans around the workspace.
Drag a selected wall, light, or sunlight area with no active toolMoves the selected element or selected group on the grid.
Arrow keysNudge selected elements by 0.25 tile.
Shift + Arrow keysNudge selected elements by 1 tile.
Ctrl + Arrow keysNudge selected elements by a fine screen-pixel step.
Middle mouse dragPans even while a placement tool is selected.
Reset ViewReturns zoom and pan to the fitted default view.

Zoom and pan affect only your editor view. Snapping, wall drawing, light placement, and texture calibration continue to use the same grid coordinates.

Texture Calibration

Background textures are no longer just stretched to the map bounds. Use Calibrate Texture... for direct numeric alignment or Guided Calibration... for the same two-step helper flow used by the standard Map plugin.

ActionWhat it does
Calibrate Texture...Fine-tune the texture scale and offset with live preview values.
Guided Calibration...Pick a centre reference point, then pick the next horizontal or vertical tile boundary to lock the texture to the grid.

The builder stores texture calibration relative to the map grid, so the alignment stays stable even if you later resize the DM pane.

In the manual calibration dialog, the small + and - buttons nudge offsets by a few pixels, while the arrow buttons beside them move the texture by exactly one current grid tile. Use the tile arrows when the image is scaled correctly but shifted by one or more squares.

Wall Tools

Open a second pane with Wall Tools to control wall editing. This pane now owns the wall-specific placement modes instead of the main builder toolbar.

Wall Tools actionWhat it does
Type: Soft / Hard / Door / FeatureChoose whether newly drawn segments are soft walls, hard walls, doors, or direction-specific feature walls.
Door: Visible / HiddenChoose whether newly drawn doors are shown to players or kept secret. This row only affects the Door type.
Draw: LineClick and drag in the builder pane to place one straight wall segment using the selected wall type.
Draw: RectClick and drag in the builder pane to place a rectangular ring of four wall segments using the selected wall type.
Stop EditingLeave wall or light placement mode without changing the draft.
Optimize WallsMerges touching or overlapping straight wall segments that lie on the same line, and removes zero-length wall stubs.
Clear All WallsRemove every wall segment from the current builder draft.

Choose the wall type first, then choose the drawing mode. Soft walls are shown as lighter dashed lines, hard walls are shown as stronger solid lines, doors are shown with a door icon at the segment midpoint, and feature walls are shown as two slightly separated side lines plus a small arrow pointing toward their front side. Open sides use a dotted line, Soft sides use a dashed line, and Hard sides use a solid line. All wall types can be selected, moved, renamed, grouped, and exported like any other wall segment.

Right-click a feature wall to define its front and back side behavior. The front side is the side the arrow points toward; the back side is the opposite side. Each side can be set to Open, Soft, or Hard. Open lets sight and light pass from that side, Soft blocks sight and bright light while letting dim light spread through, and Hard blocks sight, bright light, and dim light. This is useful for ledges, balconies, and height differences where one side should see over the wall while the other side cannot.

Visible doors show a door icon to the players during play; hidden doors only show that icon to the DM. Both visible and hidden doors still appear in the builder so you can review the whole map layout before exporting. During play, the DM can click a door icon on the DynamicMap minimap to open or close that door.

The difference appears during play in DynamicMap. Soft walls, hard walls, closed doors, and blocking sides of feature walls block player-character sightlines and bright light. Soft walls and Soft feature-wall sides let dim light spread through them for a softer scattering look, while hard walls, closed doors, and Hard feature-wall sides also block dim light.

Use Optimize Walls after drawing or moving several wall pieces that should behave like one continuous wall. The builder clears the current selection after optimization and remaps groups onto the merged wall where possible. Soft walls and hard walls are kept separate during optimization so their lighting behavior is preserved. Doors are kept as separate segments so each one keeps its own icon and visible/hidden setting. Feature walls are also kept separate so their arrow direction and side behavior remain unchanged.

Light Browser

Open a second pane with Light Browser to pick from ready-made point-light presets such as Torch, Lantern, Campfire, or Moonbeam. After you press Use on a preset, the main builder pane immediately switches into light placement mode.

Every newly placed light uses that selected range and colour until you choose another preset. The Light Browser also lets you stop placement mode or clear all lights without going back to the main builder pane. Clearing all lights asks for confirmation before anything is removed.

Use Draw Sunlight Area in the Light Browser to mark outside or naturally lit regions. Click the builder canvas to add polygon vertices, then click back near the first vertex or double-click to finish the area. Sunlight areas are saved with the draft and exported with gameplay bundles for the Dynamic Map lighting workflow.

Clear Sunlight Areas removes every sunlight polygon from the current draft after a confirmation dialog.

Outline Browser

Open another pane with Outline Browser for a Blender-style overview of the current draft. It shows user-created groups plus all placed lights, sunlight areas, and walls in one browser, so you can inspect the whole structure without hunting across the canvas.

Outline Browser actionWhat it does
Select an itemHighlights that wall, light, or sunlight area in the main builder canvas.
Select a groupSelects every wall, light, or sunlight area linked to that group.
Ctrl-click another itemAdds or removes that item from the current outline selection.
Right-click > RenameRenames one selected group, wall, or light.
Right-click > Group SelectedCreates a saved group from the currently selected walls and lights.
Right-click a group > Remove GroupRemoves the selected group entry but keeps its walls and lights on the map.
Remove SelectedDeletes every currently selected wall, light, or sunlight area.
Disable / Enable LightTurns one selected light source off or back on without deleting it.
Clear SelectionLeaves the outline item list intact but removes the current highlights.

Naming and grouping controls live in the outline right-click menu so the pane stays compact during normal editing.

Disabled lights stay in the outline and appear as subdued markers in the builder canvas, so you can still keep track of them and switch them back on later.

Groups are saved with the builder draft. If grouped walls, lights, or sunlight areas are deleted later, the group automatically forgets those missing elements.

As new Dynamic Map Builder element types are added in future updates, they are expected to appear in this outline pane as well.

Construction Sites

Use the Site controls in the top DM toolbar to manage named builder scenes. These controls are visible only while the Dynamic Map Builder workspace is selected. A construction site is a saved Dynamic Map Builder work-in-progress that can be loaded later.

Toolbar actionWhat it does
Site selectorShows saved construction sites. Choosing one loads it into the builder.
New...Creates a new empty construction site and makes it active.
SaveSaves the current builder document to the active construction site.
Save As...Saves the current builder document under a new construction-site name.
DeleteDeletes the selected saved construction-site file after confirmation.
Export...Writes the current builder document as a gameplay-ready Dynamic Map bundle.

When a construction site is active, builder edits autosave back to that site so you can close the app and continue later. Loading another construction site clears the current outline selection and shows the loaded walls, lights, groups, and texture calibration.

Export... creates a .dynamicmap bundle for gameplay use. The bundle includes the map size, background texture when the source image is available, texture calibration, walls with their soft, hard, door, or feature wall kind, door visibility, feature-wall side behavior, lights, and sunlight areas. It leaves out builder-only details such as construction-site names, wall, light, and sunlight-area labels, builder element ids, outline groups, and temporary layer visibility. Wall topology is optimized automatically during export, so touching wall pieces of the same kind on the same line are combined in the gameplay bundle even if you have not pressed Optimize Walls manually. Feature walls are not combined because their arrow direction and side behavior are part of the authored map.

Builder Persistence

Named construction sites are stored in ~/.tabletopcontrol/dynamic-map-construction-sites/. The currently active site is remembered in ~/.tabletopcontrol/dynamic-map-builder-active-site.properties.

If no named construction site is active, the builder still keeps a scratch autosave draft in ~/.tabletopcontrol/dynamic-map-builder-draft.properties.

Use Export... in the builder toolbar when you want a gameplay bundle. The editable construction-site files stay separate from exported .dynamicmap bundles, so you can keep your working notes and groups in the builder without exposing them during play.

Gameplay bundle import is still future work. Construction sites remain the editable working format for the builder.
